# 2027 パブリックコミットメント

2027年の目標を1人30〜50個立てて、公開する取り組みのサイトです。

- 誰でも、メンバー全員の目標と進み具合を見られます
- 招待されたメンバーは、メールに届くリンクでログインして、自分の目標を書き込めます
- 書き込めるのは自分の目標だけです（ほかの人の行は変えられません）

## しくみ

| ファイル | 役割 |
|---|---|
| `index.html` / `app.js` | サイト本体（GitHub Pages で表示） |
| `config.js` | 保存先（Supabase）の接続先 |
| `supabase/schema.sql` | テーブルと権限。Supabase の SQL Editor で1回実行する |
| `supabase/seed_kanasugi.sql` | 金杉さんの最初の目標19個 |
| `template/2027目標リスト_テンプレート.xlsx` | 自分たちでも同じことをしたい人向けのテンプレート |

## メンバーを増やすとき

Supabase の Authentication → Users → Invite user で、メンバーのメールアドレスを招待します。
招待された人はサイトの「メンバーのログイン」からメールアドレスを入れると、ログイン用のリンクが届きます。

## 書き方のルール

1. 1人30〜50個。大きい目標と小さい目標を混ぜてよい
2. 目標は言い切りで書く（「〜したい」ではなく「〜する」）
3. 達成基準は、数字か、他の人が見て判定できる状態で書く
4. 期限を入れる。年内いっぱいなら 2027/12/31
5. ステータスは月に1回更新する
